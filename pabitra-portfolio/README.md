# Pabitra Mohontha — WordPress Portfolio Theme

A custom WordPress portfolio theme rebuilt around the supplied reference page. The visual direction keeps the reference's editorial layout, charcoal hero, mist/sage section transitions, deep blue expertise section, outlined buttons, sticky navigation, animated project previews, interactive expertise tabs, project cards, and responsive mobile menu.

## Installation

1. In WordPress, open **Appearance → Themes → Add New → Upload Theme**.
2. Upload `pabitra-mohontha-reference-style-theme.zip` and activate it.
3. Set a static homepage under **Settings → Reading** if your site does not already use the front page.

## Personal assets to add

- Add your portrait as `assets/pabitra.jpg` to replace the built-in `PM` portrait placeholder.
- The CV PDF was not present in the supplied ZIP, so the Resume section now offers an email link to request a copy rather than linking to a missing file.

## Notes

- The reference layout and interactions are implemented in `header.php`, `front-page.php`, `footer.php`, `assets/css/main.css`, and `assets/js/main.js`.
- Update your personal details, project URLs, and project descriptions in `front-page.php` and `header.php` when needed.
- This theme does not add a language switcher.
